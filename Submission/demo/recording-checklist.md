# Recording checklist
- [ ] Hosted HTTPS URL opens in Quest Browser; hand tracking enabled in Settings
- [ ] Quest: use Meta's built-in casting/recording (or Meta Quest Developer Hub capture); emulator: record the browser window
- [ ] Reload page to reset the scenario before each take; use `?onboard=0` to skip the welcome card if desired
- [ ] Seated, good lighting for hand tracking
- [ ] Narration recorded separately (quiet room); keep total < 3:00
- [ ] Captions: "Scenario data fictional. Recovery simulated. AI: deterministic fallback."
- [ ] Export MP4 (1080p+), check length < 180 s
- [ ] Upload as PUBLIC on YouTube/Vimeo; paste URL into Devpost
