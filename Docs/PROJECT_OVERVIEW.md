# Project Overview

**Trustfall — The AgentOps Command Center.** Track: Productivity. Division: New Experience. Platform: Meta Quest (Quest Browser / WebXR), hands-first.

Problem: autonomous AI agents change infrastructure; when something breaks, responders must reconstruct who did what, whether it was allowed, and whether the evidence can be trusted. Flat dashboards hide the relationships.

Solution: a spatial workspace where service health, agent actions, permission policy, cryptographic verification and recovery are connected objects you can inspect with your hands. Core principle: *a valid signature proves integrity, not authorization.*

Scope: one fully worked, fictional incident. See `LIMITATIONS.md` for what is and isn't verified.
